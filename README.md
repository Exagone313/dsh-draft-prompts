# dsh-draft-prompts

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![npm version](https://img.shields.io/npm/v/@exagone313/dsh-draft-prompts)](https://www.npmjs.com/package/@exagone313/dsh-draft-prompts)
[![GitHub release](https://img.shields.io/github/v/release/Exagone313/dsh-draft-prompts)](https://github.com/Exagone313/dsh-draft-prompts/releases)

English | [中文](README.zh.md)

A [DeepSeek Harness](https://deepseek.com/harness) that adds a right-sidebar tab
for drafting prompts. Drafts are stored in
`$DSH_HOME/storages/draft_prompts.json`.

## Install

```sh
dsh plugin --profile web add @exagone313/dsh-draft-prompts
```

Restart dsh afterwards.

## Remove

```sh
dsh plugin --profile web remove @exagone313/dsh-draft-prompts
```

Restart dsh afterwards.
